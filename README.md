# 英语商业街 · English High Street

当前默认入口是第一人称 3D 小店与商业街：走近店内电脑，从 30 种商品中自行选择进货种类和数量，确认扣款、等车到门口签收、搬箱上架，再接待 6 种外形的顾客、扫码收款，当天用回款继续进货。电脑集中提供进货、营业 / 日结、扩容、设备商店、装修和商业街六个应用。现有货架、冷柜、收银台和免费电脑桌可以在装修平面图中移动、旋转。店外每天会有 Sam 或 Ellis 一位具名“街头邻居”；只有 Sam 带陪伴犬 Patch。玩家靠近后可征得同意聊天，也可自愿从小店资金提供 £1 或 £2 现金帮助；不给钱没有惩罚、经验或成就差异。

> £12 本金 → 电脑自选进货 → 短时配送与签收 → 搬运上架 → 09:00 开门 → 售出回款 → 当天再次补货、持续接客 → 19:00 打烊收尾 → 到电脑日结

本轮电脑入口、循环补货、12 分钟营业与 v15 存档规则以 [店内电脑与当日循环经营](./docs/SHOP_COMPUTER.md) 为准。店铺成长、实体扩建与自由摆放的早期说明见 [自由装修第一版](./docs/SHOP_RENOVATION.md)；营业钟最初实现及后续路线见 [营业时间第一版](./docs/BUSINESS_TIME.md)，选品与交易见 [自选进货与30种商品经营](./docs/PRODUCT_SHOPPING.md)。顾客外形与语料见 [顾客外形与常用语料库](./docs/CUSTOMER_VARIETY.md)，街头邻居的角色、对话、陪伴犬与尊重性边界见 [英国街头邻居](./docs/STREET_NEIGHBOURS.md)。现金操作见 [现金收款](./docs/CASH_PAYMENT.md)，空箱处理见 [空箱回收](./docs/CRATE_RECYCLING.md)。早期街景与邻店条件见 [商业街与每日送货](./docs/STREET_DELIVERY.md)，模型清单见 [商品素材库](./docs/PRODUCT_ASSET_LIBRARY.md)。早期文档中的旧时长、每日送货及远程管理快捷键不再适用于当前版本。

## 在电脑上玩

要求 Node.js 22 或更高，本次使用 Node 26。目标设备是 Mac / PC 键盘加鼠标；手机、手柄不在本轮范围内。

~~~bash
npm install
npm run build
npm run play
~~~

打开 [3D 小店试玩](http://localhost:4200/)。4200 是生产构建的 **preview**，不是热更新开发服务；只监听本机，端口被占用时明确报错。改代码或替换音频后需重新 `npm run build` 再刷新，单独刷新不会生成新版本。

开发时运行 `npm run dev:3d`，入口为 [localhost:4199](http://localhost:4199/)，支持自动刷新。4199、4200 及 localhost / 127.0.0.1 分别拥有独立浏览器存档；搬进度请用 JSON 导出/导入。不要再用之前旧项目占用的 4174 来判断当前游戏。

| 打开店内电脑 | 走近电脑、看向屏幕按 E；默认在门内左侧，手持物品保留 |

| 开门 / 提前打烊 / 日结 | 电脑「营业 / 日结」；营业牌 E 也可开门，日结须回电脑 |

玩家基础走速提高约 50%；按住 Shift 以普通走速的 1.8 倍持续移动，松开就恢复。低帧率时分小步检查碰撞，避免加速穿墙；详细参数与回归说明见 [玩家移动与加速](docs/PLAYER_MOVEMENT.md)。

上方方向/距离提示帮助找物品。看向可操作实体时，底部显示具体动作，实体有金色边线。底部按钮与键盘使用同一真实目标，不能隔空上架。

收银互动时自动释放鼠标，让语音按钮可点，不为此打开暂停菜单。打开电脑或现金找零面板时暂停顾客与玩家移动；返回小店后鼠标仍可点击，按 Tab 主动切回转头。找零面板内 Tab 正常移动按钮焦点，E 不会代替确认收款；电脑内的输入框获得焦点时，B / U / P / M 不会切换应用。内嵌浏览器若不允许鼠标锁定，继续使用拖动画面或 IJKL。

电脑、普通暂停、近看学习和街头邻居对话会暂停营业钟与配送钟；现金找零面板只暂停角色动作，正常找零时营业钟和配送继续。主动重听或慢读期间两个时钟都暂停，语音结束、停止或失败后恢复；仅释放鼠标不会暂停营业或配送。成功下单后自动退出电脑，让货车开始推进。

## 背景音乐与操作反馈

点击“开始第一天 / 继续营业”后播放 Kevin MacLeod 的 **Local Forecast 原版**，整曲持续循环。音乐随游戏发布，不需要外部播放器或运行时连接音乐网站；首次点击后才载入并解码，不阻塞小店开始。

- 顾客从街道远处沿人行道走来，真正跨进店门才响门铃、自动问候；成功上架、扫码、收款分别播放轻碰、短提示和收款音。重复或失败操作不会误响，读取存档本身不响门铃。来客路线与阶段恢复规则见 [顾客从街道进店](./docs/CUSTOMER_ARRIVALS.md)。
- 本地录音或浏览器合成英语开始播放时，音乐平滑降低到平时的 22%，音效也会变轻；语音结束、失败或取消后恢复。
- 暂停、切出窗口、进入只读或离开页面时停止背景声音；继续营业后从暂停处恢复。近看商品时可继续听音乐与单词。
- 按 **Esc → 声音与音乐**，可单独开关循环音乐，分别调整音乐、操作音效和英语发音音量。默认音乐 22%、音效 50%、发音 70%；音效调到 0 即关闭。设置保存在当前浏览器，兼容此前设置与游戏存档。
- 音乐加载或设备声音不可用不会阻止进货、收款等操作；可在声音设置查看状态，检查设备后点击继续营业重试。

音乐作者、来源及许可在游戏内“声音与音乐”和 [音乐来源记录](./public/assets/sim3d/audio/music-SOURCES.md)保留。四种短音效由项目程序合成，没有新增第三方音效包。

## 营业时间与打烊

- 准备阶段停在 08:30，不限时；上架后手动开门，从 09:00 营业到 19:00，对应 **12 分钟（720,000 毫秒）有效营业时间**。准备、管理、学习暂停和收尾会延长实际游玩时间。
- 每天顾客人数不设上限，仍同时一位。上一位真正离店后间隔 **2–4 秒**安排下一位，间隔由存档中的种子稳定决定；没有货架库存时暂停来客，上架后自动恢复，营业钟继续。
- 新顾客从店门左侧或右侧约 19 米外出现，沿街走近再进店。沿街步速为 **2.2 米/秒**，店内为 **1.7 米/秒**，取货停顿为 **0.2 秒**；离店也按所在街道或店内区域使用对应速度。行走动画随步速调整，步行时间计入有效营业时间。
- 街上每天稳定出现 Sam 或 Ellis 其中一人，次日轮换；他们不会自动索要钱或阻挡进店路线。对话、自愿帮助和重听期间营业钟暂停。
- 18:30 提醒即将打烊；19:00 自动停止新顾客和新采购，也可以在电脑确认提前打烊。当前顾客可以完成或安全取消订单，已付款配送继续按顺序送达。等顾客离店、待付款商品处理完、全部配送签收且货车驶离后，回电脑确认日结；不会自动弹出经营应用。
- 营业钟和配送钟独立：准备期与打烊收尾期仍能配送。电脑、普通暂停、近看商品、主动重听/慢读及切出窗口时都冻结；普通扫码、现金找零和仅释放鼠标继续计时。返回或刷新不补算离线时间，不补发收入。
- 零单日也能结束；累计日结天数照常记录，但咖啡店“首次有收款的营业日结”条件不计零单日。天空与灯光暂不随时间变化，排在下一版。

## 第一天怎么玩

1. 新存档有 £12，电脑免费。先走到门内左侧电脑前，看向屏幕按 E，点击「进货」。按分类或中英文搜索，再逐项设置数量；清单默认全为 0，只有自己选择并确认后才扣款。可先选牛奶 3 件、面包 3 件，共 £6.90，也可以少量选一种商品。
2. 下单后自动退出电脑。货车空闲时本单正常需 12 个有效秒备货与到店；靠近停稳的车，空手按 E 签收。搬起对应货箱，按 F 查看实物和双语名称，再按价签分区上架；空箱可送到店门外右侧绿色回收点按 E 回收，每个新进货空箱获得 £0.05，立即清除并释放卸货位，不设容量上限。至少一种商品上架后，到电脑「营业 / 日结」或营业牌开门。
3. 顾客只从已上架商品中挑选 1–2 种，每种 1 件；仅售一种商品也能营业。新游戏第一位刷卡，扫描完后按 E 收款；第二位固定现金，之后混合两种方式。现金客人扫描完后按 E 打开钱箱，先收钱，再点击面额找零；金额正确才可确认，刚好付清则无需找零。
4. 没听清可按 R，或点击“请再说一遍”听请求句和慢速重播；学习播放期间暂停营业钟和配送，不要求开麦。
5. 第一单卖出后，可以回电脑用所得资金再下单、签收和上架，当天不限采购次数，也不在第三位顾客后结束。19:00 打烊或确认提前打烊后，完成当前交易、等待顾客离店，逐单签收已付款配送并等车驶离，再到电脑「营业 / 日结」确认日结。
6. 资金足够时，可在电脑点击「扩容」或按 U 花 £8，把每种商品的普通货位从 4 增至 8；日结后可从「营业 / 日结」开始次日，现金、未售库存和扩容结果保留。

如果只采购并上架牛奶、面包各 3 件，上述例子的收入仍为 £12、已售成本 £6.90、毛利 £5.10；未提前扩容时，日结现金为 £17.10，扩容后 £9.10。其他选品按各自进价、售价和实际成交商品核算。日结只汇总已发生的收支，不再奖励一次收入；次日不再赠送 £12。

这里三单只是核算示例，不再是一天的上限。卖完后可以补货继续营业，也可以确认提前打烊；其他采购和成交会相应改变余额。

上述余额未包含可选的空箱回收；两箱都回收会另得 £0.10。回收收入在账本单独列出，不改变商品毛利，不会在日结或刷新时重复发放。G 暂放后的用过空箱仍可拾取，只有投入回收站才释放它的卸货位置。

现金示例：牛奶与面包合计 £4，顾客交 £5，应找 £1；钱箱有对应库存时，两枚 50p 或一枚 £1 都有效。只有确认后才入账 £4，不把 £5 全算成收入。选错可撤回/清空；整个钱箱确实无法找零时，可请顾客给刚好金额或改刷卡。Esc 暂离、暂停或刷新后仍可继续，取消本单会归还商品及暂收现金。找零没有独立倒计时或罚款；正常找零期间营业钟继续，但19:00不会打断当前订单。有限教学钱箱的面额库存会保存，但不作为第二份经营资金；不接真实支付。

现金第四版把库存与本单状态显示为收银台上的实体抽屉、教学纸币、硬币和两个托盘。近景中点钱操作与原面额按钮共用一套账本；每格最多绘制 6 枚／张示意，数量标签显示实际余量。关闭钱箱不会取消本单；3D 不可用时恢复按钮操作，已有暂收款与找零仍保留。暂不包含手部递钱或抓取动画，详见 [实体钱箱与可见货币](./docs/CASH_VISUALS.md)。

普通扩容**任何阶段只看资金**，不需要先完成三单、日结或英语任务；上面的顺序只是首日建议。£8 只增加货位，不赠送商品。另在「店铺成长」可支付一次 £15 将后墙后移 3 米，增加真实空间；需处于准备或已日结阶段、双手空闲且店内无顾客。迁移的 S0 旧档保留原现金和商品，不适用上述新档数值示例。

店外现在可以步行探索商业街。送货车按订单顺序逐单配送：本单约 6 秒备货、6 秒驶入，签收后约 4 秒驶离，再处理下一单；等候签收和玩家挡车的时间另计。签收第一单不会提前发放后续商品，排队订单显示前方订单数，不把 12 秒误当作全部订单的到货时间。同品补货保留旧箱位置，容量检查包含在途商品；不会自动扣款或免费补满。咖啡店、餐厅和大商超有各自外观和只读门牌，管理详情须到电脑「商业街」查看。每日街头邻居可以继续聊多个话题；现金帮助每天只记一次，真实扣减小店资金并在当日账本单列，不改变经营等级。具体边界见 [英国街头邻居](./docs/STREET_NEIGHBOURS.md)。

## 店铺成长与装修

到电脑点击「装修」或按 P 打开平面图，选择或拖动原有 11 组设备、已购设备及独立电脑桌；0.1 米吸附、90°旋转，确认「应用布局」后生效。货架上的商品、价签、顾客取货点和收银设备同步移动。电脑桌约 1.2 × 0.55 米，木桌、显示器、主机、键盘、鼠标与交互点整体移动，不增加商品容量，也不能出售、删除或放入仓库。重叠、越界、堵门、通道不足或电脑正面不可达会阻止应用；离开时未应用的草稿会要求保留或放弃。装修免费，刷新只保留已应用布局，营业中仍须先完成日结或等待次日准备期再调整。

电脑「扩容」内的「店铺成长」子页保留两次实体扩建：首次 £15、第二次 £30，每次向后增加 3 米，与 £8 普通货架扩容分别记账。「设备商店」保留设备购买、已拥有设备与仓库。建设与经营成就沿用实际经营记录，不奖励额外现金、不代表英语掌握；第三次扩建、空间封顶后升级超市与招聘仍未开放。

## 已实现

- 一间可走动且可两次实体扩建的英式小店，原有 11 组设备、已购设备与免费电脑桌可摆放，以及门外的人行道、路面、斑马线、绿化、路灯和三家未来商铺。
- 必须近身按 E 打开的实体电脑与六个桌面应用；现金管理归入营业子页，店铺成长归入扩容子页。经营快捷键仅在电脑内有效，普通暂停、门牌与自动提示不提供远程管理入口。
- 同一套 30 种商品模型覆盖饮料、烘焙零食、冷藏、果蔬、粮食冲饮和日用品；货箱、货架、手持、近看、购物篮与收银使用实际选品。
- 默认空的 30 商品进货清单，支持分类、搜索、逐项数量和金额预览；准备和营业期间可反复采购，一辆货车按订单依次配送和签收，防止重复扣款或提前发放排队商品。

## 当前边界

- 已支持目录中的 30 种商品、基于实际库存的订单、两次实体扩建和设备购买，一次一位顾客；目录之外的新 SKU、多顾客队列、第三次扩建、超市内部经营、雇员和自动收银尚未实现。
- 营业钟已接入，但天空、日照与灯光尚未按时变化。后续顺序为昼夜视觉、客流与经济调优，再评估多人队列和天气季节，详见 [后续开发路线](./docs/BUSINESS_TIME.md#后续开发路线)。
- 咖啡店、餐厅和大商超当前只实现外观、门牌互动及成长条件；室内购物、点餐或经营玩法尚未开放。
- 自选采购有明确数量、进价与售价，但尚不包含买方询价、替代品协商和多场景语言任务。
- 手部为程序化小样精度。顾客有成人模型和站立/行走动画，专门的伸手拿货、握篮、刷卡动作尚未精修。
- 近看/听过只记为接触，不计独立掌握；高级英语服务/自动化与研究数据采集尚未接入。
- 顾客台词以及牛奶、面包词音使用本地音频；新增商品的单词和短语在支持时使用浏览器合成语音，其声线与可用性依赖设备，不宣称已有28种新品的本地录音。
- 没有登录、麦克风、运行时 LLM、云存档或 PWA。内嵌浏览器不一定支持鼠标锁定，可用拖动或 IJKL。
- 不是完整多浏览器和持续低帧统计后的性能认证，也未完成正式美术验收。
