# 英语商业街 · English High Street

当前默认入口是第一人称 3D 小店与商业街：从 30 种商品中自行选择进货种类和数量，确认扣款、门口签收、搬箱上架，再接待顾客、扫码收款、日结、扩充货位及实体扩建。现有货架、冷柜和收银台可以在装修平面图中自由移动、旋转。商品素材库与游戏使用同一套模型，不需要玩家调用代码。店外仍可查看咖啡店、餐厅和大商超，以及各自开放需要的经营等级与成就；邻店内部玩法仍在筹备。

> £12 本金 → 自选商品和数量 → 确认订货 → 门口签收 → 搬运上架 → 09:00 开门 → 持续接客 → 打烊收尾 → 日结 → 带着库存与现金进入次日

店铺成长、实体扩建与自由摆放见 [自由装修第一版](./docs/SHOP_RENOVATION.md)。当前营业规则和后续路线见 [营业时间第一版](./docs/BUSINESS_TIME.md)，选品、交易和存档规则见 [自选进货与30种商品经营](./docs/PRODUCT_SHOPPING.md)。现金操作见 [现金收款第一版](./docs/CASH_PAYMENT.md)，空箱处理见 [空箱回收](./docs/CRATE_RECYCLING.md)。街景与邻店条件见 [商业街与每日送货](./docs/STREET_DELIVERY.md)，模型清单见 [商品素材库](./docs/PRODUCT_ASSET_LIBRARY.md)。[S1 首日说明](./docs/S1_FIRST_DAY.md)及 [S0 记录](./docs/S0_3D_IMPLEMENTATION.md)保留历史验证口径。

## 在电脑上玩

要求 Node.js 22 或更高，本次使用 Node 26。目标设备是 Mac / PC 键盘加鼠标；手机、手柄不在本轮范围内。

~~~bash
npm install
npm run build
npm run play
~~~

打开 [3D 小店试玩](http://localhost:4200/)。4200 是生产构建的 **preview**，不是热更新开发服务；只监听本机，端口被占用时明确报错。改代码或替换音频后需重新 `npm run build` 再刷新，单独刷新不会生成新版本。

开发时运行 `npm run dev:3d`，入口为 [localhost:4199](http://localhost:4199/)，支持自动刷新。4199、4200 及 localhost / 127.0.0.1 分别拥有独立浏览器存档；搬进度请用 JSON 导出/导入。不要再用之前旧项目占用的 4174 来判断当前游戏。

## 操作

| 操作 | 输入 |
| --- | --- |
| 移动 | WASD 或方向键 |
| 按住加速 / 松开恢复 | Shift（左右均可）；搬箱时同样有效，无体力限制 |
| 转头 | 鼠标；不能锁定鼠标时，按住画面左键拖动 |
| 键盘备用转头 | I / J / K / L |
| 抱箱、上架、扫描、收款 | 看向目标、走近后 E；锁定鼠标时也可左键 |
| 现金找零 | 扫描完后 E 打开钱箱；点击收钱、选择面额、确认；Esc 暂离并保留本单 |
| 近看商品 / 返回 | F；拖动旋转商品，可点听单词、听搭配 |
| 安全放下货箱 / 放回单品 | G；货箱需靠近指定卸货点 |
| 回收空箱 | 抱着空箱走到店门外右侧绿色回收点，看向回收站按 E |
| 释放鼠标以点击界面 / 切回转头 | Tab；不因此主动暂停营业 |
| 重听当前顾客台词 | R，或点击“重听” |
| 重听现金交款金额 | 找零面板中 R；Shift + R 慢速重听 |
| 进货 / 普通扩容 | B / U，或点击画面中的经营入口 |
| 自由装修 / 旋转设备 | P，或点击「装修」；布局中 R 旋转，拖动或方向键移动 |
| 商业街成长 / 店铺开放条件 | M，或走近商铺门牌按 E |
| 提前打烊 / 日结 | “营业 / 日结”中确认提前打烊；收尾完成后确认日结，也可走到营业牌互动 |
| 暂停与设置 | Esc |

玩家基础走速提高约 50%；按住 Shift 以普通走速的 1.8 倍持续移动，松开就恢复。低帧率时分小步检查碰撞，避免加速穿墙；详细参数与回归说明见 [玩家移动与加速](docs/PLAYER_MOVEMENT.md)。

上方方向/距离提示帮助找物品。看向可操作实体时，底部显示具体动作，实体有金色边线。底部按钮与键盘使用同一真实目标，不能隔空上架。

收银互动时自动释放鼠标，让语音按钮可点，不为此打开暂停菜单。打开进货、日结、扩容等管理界面或现金找零面板时暂停顾客与玩家移动；返回小店后鼠标仍可点击，按 Tab 主动切回转头。找零面板内 Tab 正常移动按钮焦点，E 不会代替确认收款。内嵌浏览器若不允许鼠标锁定，继续使用拖动画面或 IJKL。

管理界面会暂停营业钟；现金找零面板只暂停角色动作，正常找零时营业钟继续。主动重听或慢读期间暂停计时，语音结束、停止或失败后恢复；仅释放鼠标不会暂停营业。

## 背景音乐与操作反馈

点击“开始第一天 / 继续营业”后播放 Kevin MacLeod 的 **Local Forecast 原版**，整曲持续循环。音乐随游戏发布，不需要外部播放器或运行时连接音乐网站；首次点击后才载入并解码，不阻塞小店开始。

- 顾客从街道远处沿人行道走来，真正跨进店门才响门铃、自动问候；成功上架、扫码、收款分别播放轻碰、短提示和收款音。重复或失败操作不会误响，读取存档本身不响门铃。来客路线与阶段恢复规则见 [顾客从街道进店](./docs/CUSTOMER_ARRIVALS.md)。
- 本地录音或浏览器合成英语开始播放时，音乐平滑降低到平时的 22%，音效也会变轻；语音结束、失败或取消后恢复。
- 暂停、切出窗口、进入只读或离开页面时停止背景声音；继续营业后从暂停处恢复。近看商品时可继续听音乐与单词。
- 按 **Esc → 声音与音乐**，可单独开关循环音乐，分别调整音乐、操作音效和英语发音音量。默认音乐 22%、音效 50%、发音 70%；音效调到 0 即关闭。设置保存在当前浏览器，兼容此前设置与游戏存档。
- 音乐加载或设备声音不可用不会阻止进货、收款等操作；可在声音设置查看状态，检查设备后点击继续营业重试。

音乐作者、来源及许可在游戏内“声音与音乐”和 [音乐来源记录](./public/assets/sim3d/audio/music-SOURCES.md)保留。四种短音效由项目程序合成，没有新增第三方音效包。

## 营业时间与打烊

- 准备阶段停在08:30，不限时；上架后手动开门，从09:00营业到19:00，对应7分钟有效营业时间。准备、学习暂停和收尾会延长实际游玩时间，一日8—10分钟仍是待试玩验证的节奏目标。
- 每天顾客人数不设上限，仍同时一位。上一位离店后间隔8—12秒再来下一位，间隔由存档中的种子稳定决定；缺货时暂停来客，营业钟继续。
- 新顾客从店门左侧或右侧约19米外出现，沿街走近再进店，不再直接出现在门口。来店途中显示方向与距离，走速仍为1.41米/秒；步行时间计入有效营业时间。
- 18:30提醒即将打烊；19:00自动停止新顾客和新采购，也可以确认提前打烊。当前顾客可以完成或安全取消订单，已付款配送仍能签收。等顾客离店、待签收和待付款商品处理完，再确认日结。
- 进货/扩容/日结等管理面板、近看商品、主动重听/慢读及切出窗口时暂停营业钟；普通扫码、现金找零和仅释放鼠标继续计时。返回或刷新不补算离线时间，不补发收入。
- 零单日也能结束；累计日结天数照常记录，但咖啡店“首次有收款的营业日结”条件不计零单日。天空与灯光暂不随时间变化，排在下一版。

## 第一天怎么玩

1. 新存档有 £12。按 B，按分类或中英文搜索商品，再逐项设置数量；清单默认全为 0，只有自己选择并确认后才扣款。可先选牛奶 3 件、面包 3 件，共 £6.90，也可以只选一种其他商品。
2. 走出店门，靠近停稳的送货车按 E 签收。搬起对应货箱，按 F 查看实物和双语名称，再按价签分区上架；空箱可送到店门外右侧绿色回收点按 E 回收，每个新进货空箱获得 £0.05，立即清除并释放卸货位，不设容量上限。至少一种商品上架后，就能到营业牌按 E 开门。
3. 顾客只从已上架商品中挑选 1–2 种，每种 1 件；仅售一种商品也能营业。新游戏第一位刷卡，扫描完后按 E 收款；第二位固定现金，之后混合两种方式。现金客人扫描完后按 E 打开钱箱，先收钱，再点击面额找零；金额正确才可确认，刚好付清则无需找零。
4. 没听清可按 R，或点击“请再说一遍”听请求句和慢速重播；学习播放期间暂停营业钟，不要求开麦。
5. 营业时间内继续接客和补货，不在第三单结束。19:00打烊或确认提前打烊后，完成当前交易、等待顾客离店并签收已付款配送，再打开“营业 / 日结”确认日结。
6. 按 U 花 £8，把每种商品的货位从 4 增至 8；之后可开始次日，现金、未售库存和扩容结果保留。

如果只采购并上架牛奶、面包各 3 件，上述例子的收入仍为 £12、已售成本 £6.90、毛利 £5.10；未提前扩容时，日结现金为 £17.10，扩容后 £9.10。其他选品按各自进价、售价和实际成交商品核算。日结只汇总已发生的收支，不再奖励一次收入；次日不再赠送 £12。

这里三单只是核算示例，不再是一天的上限。卖完后可以补货继续营业，也可以确认提前打烊；其他采购和成交会相应改变余额。

上述余额未包含可选的空箱回收；两箱都回收会另得 £0.10。回收收入在账本单独列出，不改变商品毛利，不会在日结或刷新时重复发放。G 暂放后的用过空箱仍可拾取，只有投入回收站才释放它的卸货位置。

现金示例：牛奶与面包合计 £4，顾客交 £5，应找 £1；两枚 50p 或一枚 £1 都有效。只有确认后才入账 £4，不把 £5 全算成收入。选错可撤回/清空；Esc 暂离、暂停或刷新后仍可继续。取消本单会归还商品及暂收现金。找零没有独立倒计时或罚款；正常找零期间营业钟继续，但19:00不会打断当前订单。钱箱暂不限库存，不接真实支付。

普通扩容**任何阶段只看资金**，不需要先完成三单、日结或英语任务；上面的顺序只是首日建议。£8 只增加货位，不赠送商品。另在「店铺成长」可支付一次 £15 将后墙后移 3 米，增加真实空间；需处于准备或已日结阶段、双手空闲且店内无顾客。迁移的 S0 旧档保留原现金和商品，不适用上述新档数值示例。

店外现在可以步行探索商业街。送货车每个游戏日到店，营业期间可补单，日结后离开；不会自动扣款或免费补满。咖啡店、餐厅和大商超有各自外观和可互动门牌，按 M 可查看等级、成就及当前进度。条件未满足显示“暂未开放”，满足后显示“条件已达成·筹备中”；邻店内部玩法还未开放。具体规则见 [商业街与每日送货](./docs/STREET_DELIVERY.md)。

## 店铺成长与装修

按 P 打开平面图，选择或拖动现有 11 组设备；0.1 米吸附、90°旋转，确认「应用布局」后生效。货架上的商品、价签、顾客取货点和收银设备同步移动。重叠、越界、堵门或通道不足会提示并阻止应用；离开时未保存的草稿会要求保留或放弃。装修免费，刷新只保留已应用布局。

店面由约 62.6 m² 扩至 83.0 m²，£15 店面扩建和 £8 货架扩容分别记账。建设与经营有 9 项成就，等级沿用真实收款经验，不奖励额外现金、不代表英语掌握。本版只开放小卖铺第一次实体扩建；后续两次扩建、空间封顶后升级超市、招聘和新设备购买尚未接入。

## 已实现

- 一间可走动且可首次实体扩建的英式小店，11 组设备自由移动旋转，以及门外的人行道、路面、斑马线、绿化、路灯和三家未来商铺。
- 同一套 30 种商品模型覆盖饮料、烘焙零食、冷藏、果蔬、粮食冲饮和日用品；货箱、货架、手持、近看、购物篮与收银使用实际选品。
- 默认空的进货清单，支持分类、搜索、逐项数量和金额预览；按所选商品真实扣款，门口签收后搬箱上架，防止重复扣款或发货。
- 根据已付款订单、日结和货架扩容记录显示经营等级、商铺开放条件与完成进度，不把经营等级当作英语掌握证明。
- 08:30不限时准备，09:00—19:00为7分钟有效营业；每天顾客不封顶、同时一位，离店后按8—12秒间隔持续接客。
- 四种男女顾客、35句场景台词与70段男女配音（含现金请求及交款金额）；牛奶、面包沿用本地单词与短语录音，其他商品可使用浏览器朗读，并明确标示音源。
- 动态订单和实际商品小票，支持单品结账；逐件扫描去重、付款防重复，普通容量升级只查资金。
- 刷卡与现金混合付款；现金可选不同的正确找零组合，保存暂收与零钱托盘，成交小票记录交付、找零和净收入。
- 绿色空箱回收站，无容量上限；箱子投入后移除并释放卸货位，新进货空箱每箱 £0.05，同批来源和顾客返货不重复奖励。
- 到点或确认提前打烊后停止新客和采购，当前订单与已付款配送可安全收尾；日结区分营业收入、空箱回收收入、采购支出、已售成本、毛利、扩容支出和现金，库存、资金和升级延续到次日。
- 独立 v10 存档、上一有效快照、JSON 校验导入/导出、两步重开、多标签写入保护；完整校验迁移 v9/v8/v7/v6/v5/v4/v3，保存布局、扩建、营业时间、来客等待、顾客与支付阶段，保留原资金、库存、订单、收货、回收、日结和室外位置。v9营业钟与v8现金和找零进度原样恢复；v7及更早旧交易与活跃顾客按刷卡兼容，不额外发钱或补发奖励。
- 暂停/失焦保护、灵敏度、流畅画质、减少动态与独立声音设置；Local Forecast 连续循环，英语语音自动压低音乐，四种操作音效只在成功操作时触发。
- [旧 2D 原型](http://localhost:4200/?legacy=1) 及其存档独立保留，不迁移、不删除。

## 当前边界

- 已支持目录中的 30 种商品和基于实际库存的订单，一次一位顾客；目录之外的新 SKU、多顾客队列、第二/三次扩建、超市内部经营、雇员和自动收银尚未实现。
- 营业钟已接入，但天空、日照与灯光尚未按时变化。后续顺序为昼夜视觉、客流与经济调优，再评估多人队列和天气季节，详见 [后续开发路线](./docs/BUSINESS_TIME.md#后续开发路线)。
- 咖啡店、餐厅和大商超当前只实现外观、门牌互动及成长条件；室内购物、点餐或经营玩法尚未开放。
- 自选采购有明确数量、进价与售价，但尚不包含买方询价、替代品协商和多场景语言任务。
- 手部为程序化小样精度。顾客有成人模型和站立/行走动画，专门的伸手拿货、握篮、刷卡动作尚未精修。
- 近看/听过只记为接触，不计独立掌握；高级英语服务/自动化与研究数据采集尚未接入。
- 顾客台词以及牛奶、面包词音使用本地音频；新增商品的单词和短语在支持时使用浏览器合成语音，其声线与可用性依赖设备，不宣称已有28种新品的本地录音。
- 没有登录、麦克风、运行时 LLM、云存档或 PWA。内嵌浏览器不一定支持鼠标锁定，可用拖动或 IJKL。
- 不是完整多浏览器和持续低帧统计后的性能认证，也未完成正式美术验收。
