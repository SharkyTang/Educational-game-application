# 英语商业街 · English High Street

当前默认入口是第一人称 3D 小店与商业街：从 30 种商品中自行选择进货种类和数量，确认扣款、门口签收、搬箱上架，再接待顾客、扫码收款、日结和扩充货位。商品素材库与游戏使用同一套模型，不需要玩家调用代码。店外仍可查看咖啡店、餐厅和大商超，以及各自开放需要的经营等级与成就；邻店内部玩法仍在筹备。

> £12 本金 → 自选商品和数量 → 确认订货 → 门口签收 → 搬运上架 → 开门营业 → 三单收款 → 日结 → 带着库存与现金进入次日

当前选品、交易和存档规则见 [自选进货与30种商品经营](./docs/PRODUCT_SHOPPING.md)。空箱处理见 [空箱回收](./docs/CRATE_RECYCLING.md)。街景与邻店条件见 [商业街与每日送货](./docs/STREET_DELIVERY.md)，模型清单见 [商品素材库](./docs/PRODUCT_ASSET_LIBRARY.md)。[S1 首日说明](./docs/S1_FIRST_DAY.md)及 [S0 记录](./docs/S0_3D_IMPLEMENTATION.md)保留历史验证口径。

## 在电脑上玩

要求 Node.js 22 或更高，本次使用 Node 26。目标设备是 Mac / PC 键盘加鼠标；手机、手柄不在本轮范围内。

~~~bash
npm install
npm run build
npm run play
~~~

打开 [3D 小店试玩](http://localhost:4200/)。4200 是生产构建的 **preview**，不是热更新开发服务；只监听本机，端口被占用时明确报错。改代码或替换音频后需重新 `npm run build` 再刷新，单独刷新不会生成新版本。

开发时运行 `npm run dev:3d`，入口为 [localhost:4199](http://localhost:4199/)，支持自动刷新。4199、4200 及 localhost / 127.0.0.1 分别拥有独立浏览器存档；搬进度请用 JSON 导出/导入。不要再用之前旧项目占用的 4174 来判断当前游戏。

## 操作

| 操作 | 输入 |
| --- | --- |
| 移动 | WASD 或方向键 |
| 按住加速 / 松开恢复 | Shift（左右均可）；搬箱时同样有效，无体力限制 |
| 转头 | 鼠标；不能锁定鼠标时，按住画面左键拖动 |
| 键盘备用转头 | I / J / K / L |
| 抱箱、上架、扫描、收款 | 看向目标、走近后 E；锁定鼠标时也可左键 |
| 近看商品 / 返回 | F；拖动旋转商品，可点听单词、听搭配 |
| 安全放下货箱 / 放回单品 | G；货箱需靠近指定卸货点 |
| 回收空箱 | 抱着空箱走到店门外右侧绿色回收点，看向回收站按 E |
| 释放鼠标以点击界面 / 切回转头 | Tab；不因此主动暂停营业 |
| 重听当前顾客台词 | R，或点击“重听” |
| 进货 / 普通扩容 | B / U，或点击画面中的经营入口 |
| 商业街成长 / 店铺开放条件 | M，或走近商铺门牌按 E |
| 日结 | 画面中的“营业 / 日结”，或收尾时走到营业牌互动 |
| 暂停与设置 | Esc |

玩家基础走速提高约 50%；按住 Shift 以普通走速的 1.8 倍持续移动，松开就恢复。低帧率时分小步检查碰撞，避免加速穿墙；详细参数与回归说明见 [玩家移动与加速](docs/PLAYER_MOVEMENT.md)。

上方方向/距离提示帮助找物品。看向可操作实体时，底部显示具体动作，实体有金色边线。底部按钮与键盘使用同一真实目标，不能隔空上架。

收银互动时自动释放鼠标，让语音按钮可点，不为此打开暂停菜单。打开进货、日结、扩容等管理界面时才暂停顾客；返回小店后鼠标仍可点击，按 Tab 主动切回转头。内嵌浏览器若不允许鼠标锁定，继续使用拖动画面或 IJKL。

## 背景音乐与操作反馈

点击“开始第一天 / 继续营业”后播放 Kevin MacLeod 的 **Local Forecast 原版**，整曲持续循环。音乐随游戏发布，不需要外部播放器或运行时连接音乐网站；首次点击后才载入并解码，不阻塞小店开始。

- 顾客真正入店时响门铃；成功上架、扫码、收款分别播放轻碰、短提示和收款音。重复或失败操作不会误响，读取存档也不会补响门铃。
- 本地录音或浏览器合成英语开始播放时，音乐平滑降低到平时的 22%，音效也会变轻；语音结束、失败或取消后恢复。
- 暂停、切出窗口、进入只读或离开页面时停止背景声音；继续营业后从暂停处恢复。近看商品时可继续听音乐与单词。
- 按 **Esc → 声音与音乐**，可单独开关循环音乐，分别调整音乐、操作音效和英语发音音量。默认音乐 22%、音效 50%、发音 70%；音效调到 0 即关闭。设置保存在当前浏览器，兼容此前设置与游戏存档。
- 音乐加载或设备声音不可用不会阻止进货、收款等操作；可在声音设置查看状态，检查设备后点击继续营业重试。

音乐作者、来源及许可在游戏内“声音与音乐”和 [音乐来源记录](./public/assets/sim3d/audio/music-SOURCES.md)保留。四种短音效由项目程序合成，没有新增第三方音效包。

## 第一天怎么玩

1. 新存档有 £12。按 B，按分类或中英文搜索商品，再逐项设置数量；清单默认全为 0，只有自己选择并确认后才扣款。可先选牛奶 3 件、面包 3 件，共 £6.90，也可以只选一种其他商品。
2. 走出店门，靠近停稳的送货车按 E 签收。搬起对应货箱，按 F 查看实物和双语名称，再按价签分区上架；空箱可送到店门外右侧绿色回收点按 E 回收，每个新进货空箱获得 £0.05，立即清除并释放卸货位，不设容量上限。至少一种商品上架后，就能到营业牌按 E 开门。
3. 顾客只从已上架商品中挑选 1–2 种，每种 1 件；仅售一种商品也能营业。听见问候和刷卡请求后，逐件扫描，再按 E 收取实际小票金额；只有成功付款才入账。
4. 没听清可按 R，或点击“请再说一遍”听请求句和慢速重播，不要求开麦。
5. 完成三单并等最后一位顾客离店，再打开“营业 / 日结”确认日结。
6. 按 U 花 £8，把每种商品的货位从 4 增至 8；之后可开始次日，现金、未售库存和扩容结果保留。

如果只采购并上架牛奶、面包各 3 件，上述例子的收入仍为 £12、已售成本 £6.90、毛利 £5.10；未提前扩容时，日结现金为 £17.10，扩容后 £9.10。其他选品按各自进价、售价和实际成交商品核算。日结只汇总已发生的收支，不再奖励一次收入；次日不再赠送 £12。

上述余额未包含可选的空箱回收；两箱都回收会另得 £0.10。回收收入在账本单独列出，不改变商品毛利，不会在日结或刷新时重复发放。G 暂放后的用过空箱仍可拾取，只有投入回收站才释放它的卸货位置。

普通扩容**任何阶段只看资金**，不需要先完成三单、日结或英语任务；上面的顺序只是首日建议。当前只做一次 £8 的货位扩容，不是买新房间、扩店或第二档升级，升级也不会赠送商品。迁移的 S0 旧档保留原现金和商品，不适用上述新档数值示例。

店外现在可以步行探索商业街。送货车每个游戏日到店，营业期间可补单，日结后离开；不会自动扣款或免费补满。咖啡店、餐厅和大商超有各自外观和可互动门牌，按 M 可查看等级、成就及当前进度。条件未满足显示“暂未开放”，满足后显示“条件已达成·筹备中”；邻店内部玩法还未开放。具体规则见 [商业街与每日送货](./docs/STREET_DELIVERY.md)。

## 已实现

- 一间可走动的英式小店，以及门外的人行道、路面、斑马线、绿化、路灯和三家未来商铺。
- 同一套 30 种商品模型覆盖饮料、烘焙零食、冷藏、果蔬、粮食冲饮和日用品；货箱、货架、手持、近看、购物篮与收银使用实际选品。
- 默认空的进货清单，支持分类、搜索、逐项数量和金额预览；按所选商品真实扣款，门口签收后搬箱上架，防止重复扣款或发货。
- 根据已付款订单、日结和货架扩容记录显示经营等级、商铺开放条件与完成进度，不把经营等级当作英语掌握证明。
- 每日三位付费顾客、一次一位：进店、取货、收银、离店，后续顾客自动接续。
- 四种男女顾客、28句随机台词与男女配音保留；牛奶、面包沿用本地单词与短语录音，其他商品可使用浏览器朗读，并明确标示音源。
- 动态订单和实际商品小票，支持单品结账；逐件扫描去重、付款防重复，普通容量升级只查资金。
- 绿色空箱回收站，无容量上限；箱子投入后移除并释放卸货位，新进货空箱每箱 £0.05，同批来源和顾客返货不重复奖励。
- 日结区分营业收入、空箱回收收入、采购支出、已售成本、毛利、扩容支出和现金；库存、资金和升级延续到次日。
- 独立 v7 存档、上一有效快照、JSON 校验导入/导出、两步重开、多标签写入保护；完整校验迁移 v6/v5/v4/v3，保留旧现金、库存、订单、收货状态、顾客与室外位置，不向旧档发放新资金、商品或回收奖励。
- 暂停/失焦保护、灵敏度、流畅画质、减少动态与独立声音设置；Local Forecast 连续循环，英语语音自动压低音乐，四种操作音效只在成功操作时触发。
- [旧 2D 原型](http://localhost:4200/?legacy=1) 及其存档独立保留，不迁移、不删除。

## 当前边界

- 已支持目录中的 30 种商品和基于实际库存的订单，一次一位顾客；目录之外的新 SKU、多顾客队列、自由装修、扩店、多雇员和自动收银尚未实现。
- 咖啡店、餐厅和大商超当前只实现外观、门牌互动及成长条件；室内购物、点餐或经营玩法尚未开放。
- 自选采购有明确数量、进价与售价，但尚不包含买方询价、替代品协商和多场景语言任务。
- 手部为程序化小样精度。顾客有成人模型和站立/行走动画，专门的伸手拿货、握篮、刷卡动作尚未精修。
- 近看/听过只记为接触，不计独立掌握；高级英语服务/自动化与研究数据采集尚未接入。
- 顾客台词以及牛奶、面包词音使用本地音频；新增商品的单词和短语在支持时使用浏览器合成语音，其声线与可用性依赖设备，不宣称已有28种新品的本地录音。
- 没有登录、麦克风、运行时 LLM、云存档或 PWA。内嵌浏览器不一定支持鼠标锁定，可用拖动或 IJKL。
- 不是完整多浏览器和持续低帧统计后的性能认证，也未完成正式美术验收。
