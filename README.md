# 英语商业街 · English High Street

在英国街角经营一家小店，把英语用在认识商品、接待顾客和收款找零中。

这是一个面向桌面浏览器的**第一人称 3D 英语学习与商店经营原型**。玩家从 £12 本金开始，亲自选品进货、签收搬箱、整理货架，再听懂顾客的请求、完成交易，逐步扩建自己的小店。

**当前状态：可本地运行的开发中原型。** 默认进入 3D 小店，仓库同时保留早期 2D 原型和独立素材预览入口。

[快速启动](#快速启动) · [基本操作](#基本操作) · [开发与验证](#开发与验证) · [文档导航](#文档导航)

## 玩法与特色

**选品进货 → 货车配送 → 签收上架 → 接待顾客 → 扫码收款 → 再次补货 → 打烊日结**

| 模块 | 当前内容 |
| --- | --- |
| 第一人称经营 | 自由走动、搬箱、逐件上架、商品近看与扫码；货物在货箱、货架、购物篮和收银台之间流转。 |
| 自主采购 | 30 种商品、6 个分类，支持中英文搜索、数量选择和金额预览；当天可多次补货，货车按订单依次配送。 |
| 情境英语 | 商品双语名称、单词与短语发音、顾客英语台词；支持重听和慢速播放，无需开麦。 |
| 收银与账目 | 刷卡、现金与找零；可点取教学纸币和硬币的 3D 钱箱，以及备用金调配、当天整单退款和打烊盘点。 |
| 店铺成长 | 普通货位扩容、两次实体扩建、设备购买与仓库，以及可移动、旋转设备的装修平面图。 |
| 商业街互动 | 街头邻居 Sam / Ellis 轮换出现，Sam 带陪伴犬 Patch；可聊天或自愿提供现金帮助，选择不给钱没有奖励差异。 |
| 进度保存 | 浏览器本地存档、有效快照备份、JSON 导入 / 导出、旧版迁移和多标签写入保护。 |

店内实体电脑提供进货、营业 / 日结、扩容、设备商店、装修和商业街六个应用，经营管理从走近电脑开始。

## 快速启动

准备 **Node.js 22 或更高版本**及 npm，使用配有键盘和鼠标的桌面电脑。

```bash
git clone https://github.com/SharkyTang/Educational-game-application.git
cd Educational-game-application
npm ci
npm run dev:3d
```

打开 [http://localhost:4199/](http://localhost:4199/)，点击“开始第一天”。开发服务支持代码修改后自动刷新，端口被占用时会报错。

如需试玩生产构建：

```bash
npm run build
npm run play
```

打开 [http://localhost:4200/](http://localhost:4200/)。`play` 预览已有构建；修改代码或资源后，需要重新运行 `npm run build`。

### 第一天怎么玩

1. 走到店门内左侧的电脑前，看向屏幕按 **E**，进入“进货”。新档有 £12，可先买牛奶与面包各 3 件，共 £6.90，也可以少量选购一种商品。
2. 下单后等货车到店，空手靠近并按 **E** 签收。抱起货箱，按价签分区上架；空箱可送到门外右侧绿色回收点。
3. 至少一种商品上架后，到电脑“营业 / 日结”或营业牌开门。顾客会自行挑选商品并前往收银台。
4. 逐件扫码后收款。现金订单先收下顾客交款，再选择正确的找零并确认；没听清时可重听或慢速播放。
5. 用回款继续补货，打烊后完成当前订单及配送收尾，再到电脑日结，进入下一天。

准备阶段停在 **08:30**，没有时间限制。**09:00–19:00 对应 12 分钟有效营业时间**，每天顾客总数不限，同时接待一位。电脑管理、近看学习、邻居对话和主动重听等会暂停计时；普通现金找零继续计时，到点仍可完成当前订单。

完整规则、现金示例和装修说明见 [玩法指南](docs/PLAY_GUIDE.md)。

## 基本操作

| 操作 | 输入 |
| --- | --- |
| 移动 / 加速 | WASD 或方向键 / 按住 Shift |
| 观察方向 | 鼠标；无法锁定鼠标时可按住左键拖动，或使用 I / J / K / L |
| 近身互动 | 看向目标按 E：签收、搬箱、上架、扫码、收款、打开电脑或交谈 |
| 连续上架 | 抱箱并对准对应货位，鼠标锁定时按住左键逐件上架，松开停止 |
| 近看商品 / 返回 | F；近看时可拖动旋转、点击发音 |
| 放下货箱 / 放回单品 | G；货箱需靠近指定卸货点 |
| 释放鼠标 / 切回转头 | Tab |
| 重听顾客台词 | R；现金面板中 Shift + R 可慢速重听交款金额 |
| 进货 / 扩容 / 装修 / 商业街 | 先打开电脑，再点击图标或按 B / U / P / M |
| 旋转装修设备 | 装修平面图中按 R |
| 返回 / 暂停与设置 | Esc；电脑应用内返回桌面，桌面再次按 Esc 退出 |

现金近景可点交款区收钱、点钱币选择找零、点托盘撤回；也保留面额按钮和键盘操作。Tab 释放鼠标本身不会暂停营业，管理快捷键只在电脑内生效。

## 存档与声音

- 进度保存在当前浏览器的 `localStorage`。在电脑外按 Esc，可导出或导入 JSON 存档；清理浏览器站点数据前建议先导出。
- `4199` 与 `4200`、`localhost` 与 `127.0.0.1` 使用各自独立的存档，切换入口时可通过 JSON 搬迁进度。3D 与历史 2D 存档也相互独立。
- 顾客、街头邻居台词及牛奶 / 面包词音随项目提供本地音频；其他商品的单词和短语依赖浏览器可用的合成语音。
- 在“Esc → 声音与音乐”中分别调整背景音乐、操作音效和英语发音。首次点击开始后才播放声音，英语语音播放时音乐自动降低音量。

## 开发与验证

**技术栈**：TypeScript · Vite · Babylon.js（3D）· Phaser（历史 2D）· Vitest · Playwright。

| 命令 | 用途 |
| --- | --- |
| `npm run dev:3d` | 启动 3D 开发服务，固定本机端口 4199 |
| `npm run build` | 类型检查并生成 `dist/` 生产构建 |
| `npm run play` | 在本机端口 4200 预览生产构建 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm test` | 运行单元测试 |
| `npm run test:watch` | 监听并运行单元测试 |
| `npm run check` | 类型检查、单元测试与生产构建 |
| `npm run test:e2e` | Chromium 浏览器回归，自动启动本机 4201 测试服务 |

首次运行浏览器测试前，安装 Playwright 的 Chromium：

```bash
npx playwright install chromium
npm run test:e2e
```

版本验证结果与适用范围记录在相应功能文档中，参见 [实体钱箱验证记录](docs/CASH_VISUALS.md#验证记录) 和 [店内电脑验证记录](docs/SHOP_COMPUTER.md#验证记录)。这些历史记录不代表当前每个环境都已经重新通过测试。

### 项目结构

```text
src/
├── main.ts                 # 入口分流
├── sim3d/                  # 3D 场景、经营规则、交互与存档
│   ├── product-library/    # 商品模型与预览
│   └── equipment-library/  # 设备模型与预览
├── domain/                 # 历史 2D 领域类型与规则
├── game/                   # 历史 Phaser 场景
└── services/               # 历史原型存档服务
public/assets/              # 模型、贴图、配音、音乐与来源记录
tests/unit/                 # 单元测试
tests/e2e/                  # 浏览器流程测试
docs/                       # 设计、玩法、实现与验证记录
scripts/                    # 素材转换与离线语音制作脚本
```

开发服务运行后，可通过以下路径进入不同模块：

| 路径 | 内容 |
| --- | --- |
| `/` | 默认 3D 小店 |
| `/?assets=1` | 商品素材库 |
| `/?assets=equipment` | 设备素材库 |
| `/?legacy=1` | 历史 2D 原型 |

## 当前范围与后续方向

当前以一间小店的经营循环为主。咖啡店、餐厅和大商超已提供街景、门牌介绍及成长条件，内部玩法仍待开发；多顾客队列、雇员、自动收银、第三次扩建，以及随营业时间变化的昼夜光照也尚未实现。

项目使用本地进度与预制内容，尚未接入登录、云存档、麦克风输入、运行时 LLM 或 PWA。当前面向桌面键鼠操作，手机、手柄及完整跨浏览器兼容仍需后续适配与验证。

经营等级、听过单词或完成交易只代表游戏内进度；英语学习效果仍需独立评估。
