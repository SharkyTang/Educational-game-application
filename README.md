# 英语商业街 · English High Street

当前默认入口是第一人称 3D 小店 S0：真实比例的牛奶与面包、键鼠自由移动、搬箱、近看、上架、顾客自主购物、扫描和刷卡收款。这是验证操作手感和商品辨认的小样，不是完整超市模拟器或毕业研究版 P0。

> 搬起货箱 → 近看并听 milk / bread → 逐件上架 → 翻转营业牌 → 顾客取货 → 扫描与收款 → 存档续玩

## 在电脑上玩

要求 Node.js 22 或更高，本次使用 Node 26。目标设备是 Mac / PC 键盘加鼠标；手机、手柄不在本轮范围内。

~~~bash
npm install
npm run build
npm run play
~~~

打开 [3D 小店试玩](http://localhost:4200/)。服务只监听本机，固定 4200 端口，被占用时明确报错。改代码后需重新 build 再刷新。

开发时运行 `npm run dev:3d`，入口为 [localhost:4199](http://localhost:4199/)，支持自动刷新。4199、4200 及 localhost / 127.0.0.1 分别拥有独立浏览器存档；搬进度请用 JSON 导出/导入。不要再用之前旧项目占用的 4174 来判断当前游戏。

## 操作

| 操作 | 输入 |
| --- | --- |
| 移动 | WASD 或方向键 |
| 转头 | 鼠标；不能锁定鼠标时，按住画面左键拖动 |
| 键盘备用转头 | I / J / K / L |
| 抱箱、上架、扫描、收款 | 看向目标、走近后 E；锁定鼠标时也可左键 |
| 近看商品 / 返回 | F；拖动旋转商品，点击听单词 |
| 安全放下货箱 / 放回单品 | G；货箱需靠近指定卸货点 |
| 暂停、设置、释放鼠标 | Esc |

上方方向/距离提示帮助找物品。看向可操作实体时，底部显示具体动作，实体有金色边线。底部按钮与键盘使用同一真实目标，不能隔空上架。

两种商品上架后，到门口营业牌按 E 开门。顾客到收银台后逐件扫描，再按 E 刷卡收款。第二单后可在“Esc → 普通容量升级”花 £8，把每种商品的可用货位从 4 扩为 8，不设英语等级门槛。

## 已实现

- 一间可走动的英式小店，柜台、冰柜、面包架和家具碰撞。
- 折顶奶盒、蓝色旋盖、带割口与透明包装的面包；两种商品不是换色方块。
- 两个可搬货箱，首批每种 4 件免费测试货；每件商品有唯一编号与唯一归属。
- 一次一位成人顾客：进店、到货架取货、收银、离店，可接待下一位。
- 内置英式真人单词录音，英文、中文和商品实物对应。
- 单件扫描去重，£1.60 + £2.40 = £4.00；成功付款才入账，普通容量升级只查资金。
- 独立 v3 存档、上一有效快照、JSON 校验导入/导出、两步重开、多标签写入保护。
- 暂停/失焦保护、灵敏度、流畅画质、减少动态与音量设置。
- [旧 2D 原型](http://localhost:4200/?legacy=1) 及其存档独立保留，不迁移、不删除。

## 验证

~~~bash
npm run check
~~~

检查包括严格 TypeScript、领域/资产/存档/界面生命周期测试及生产构建。真实键鼠试玩的结果见 [S0 实现与验收](./docs/S0_3D_IMPLEMENTATION.md)。

`npm run test:e2e` 仍是旧 2D Chromium 回归用例，已显式走 `?legacy=1` 和独立 4201 端口。本轮不把旧用例当作 3D 验收结果。

## 当前边界

- 最多售出初始 8 件商品。再采购、完整营业日、多人队列、自由装修和扩店尚未实现；容量升级不会凭空增加库存。
- 手部为程序化小样精度。顾客有成人模型和站立/行走动画，专门的伸手拿货、握篮、刷卡动作尚未精修。
- 近看/听过只记为接触，不计独立掌握；高级英语服务/自动化与研究数据采集尚未接入。
- 单词录音已内置；完整搭配与顾客句子仍依赖浏览器语音，缺失会明确提示。
- 没有登录、麦克风、运行时 LLM、云存档或 PWA。内嵌浏览器不一定支持鼠标锁定，可用拖动或 IJKL。
- 不是完整多浏览器和持续低帧统计后的性能认证，也未完成正式美术验收。
