# Local British-English phrase audio

The eight `.wav` clips listed in `phrase-manifest.json` are **synthetic speech**,
generated locally for the game's original dialogue on 2026-08-31. They are not
recordings of a performer delivering these lines, not output from macOS system
voices, and not generated by a paid or online speech service. They must not be
credited to Judith Franck, whose separate human `milk.ogg` / `bread.ogg` recordings
retain their own attribution and CC BY 3.0 US terms in `audio-SOURCES.md`.

## Offline authoring tool, not a shipped runtime

Generation used [Piper 1.7.0](https://github.com/OHF-Voice/piper1-gpl/tree/v1.7.0),
an open-source local text-to-speech engine licensed GPL-3.0-or-later, through its
[documented Python API](https://github.com/OHF-Voice/piper1-gpl/blob/v1.7.0/docs/API_PYTHON.md).
The engine and model stay in ignored `tmp/` directories. The browser game ships
only the WAV files; it does not embed, link to, download, or run Piper. The GPL
does not automatically apply to arbitrary output of a GPL program; see the
[GNU output FAQ](https://www.gnu.org/licenses/gpl-faq.html#WhatCaseIsOutputGPL).
The model's separate permission, not the engine's code license, is the voice
source checked above.

## Reproduction

Use Python 3.9–3.12 and an isolated environment. Commands below assume `uv` is
installed and are run from the project root. Downloads are only needed while
authoring; a player never runs these commands.

```sh
uv venv --python python3 --cache-dir tmp/piper-cache tmp/piper-env
uv pip install --python tmp/piper-env/bin/python --cache-dir tmp/piper-cache piper-tts==1.7.0 onnxruntime==1.19.2 numpy==2.0.2
mkdir -p tmp/piper-models
curl -fL --retry 2 -o tmp/piper-models/cori-med.onnx https://sfo3.digitaloceanspaces.com/bkmdls/cori-med.onnx
curl -fL --retry 2 -o tmp/piper-models/cori-med.onnx.json https://sfo3.digitaloceanspaces.com/bkmdls/cori-med.onnx.json
tmp/piper-env/bin/python scripts/generate-speech-clips.py
```

The script verifies both downloads against these reviewed SHA-256 values before
loading the model:

| Input | Bytes | SHA-256 |
| --- | ---: | --- |
| `cori-med.onnx` | 63,531,379 | `1899f98e5fb8310154f3c2973f4b8a929ba7245e722b3d3a85680b833d95f10d` |
| `cori-med.onnx.json` | 7,087 | `4e4e862c06be95e268cb2edeb18eed39b4fc51c515d808ed3c51404f20e96fea` |

The canonical dialogue and URL mapping are in `src/sim3d/speechClips.ts`; the
script reads that list so spoken lines do not silently diverge from captions.
It writes RIFF/WAVE, mono 22,050 Hz, signed 16-bit PCM. The voice is synthesized
with length scale 1.24 (slower than its default), default noise settings and a
0.22-second inter-sentence pause. Excess edge silence is trimmed conservatively,
4 ms edge fades are applied, and gain is limited to 2.5× with a −3 dBFS peak
ceiling. Internal word timing is not edited or time-stretched afterward.

ONNX's random seed is fixed to 31. The shipped file hashes are recorded in
`phrase-manifest.json`; different native-library/platform builds may still
produce slightly different sample values when regenerating. Treat the manifest
as the identity of these shipped assets, not a cross-platform bit-exact promise.

## Verification and limits

Generation rejects silent/invalid output and a combined phrase size above
1,000,000 bytes. Each clip's exact caption, duration, size, SHA-256, RMS and peak
level is recorded in `phrase-manifest.json`. RIFF sizes and PCM headers are
checked independently after generation. Browser playback and interaction are
verified by the application's integration tests / interactive QA, not by this
generation script. Voice naturalness still requires human listening feedback;
these clips are not represented as final human voice acting.
