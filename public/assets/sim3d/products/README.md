# 商品模型素材库

30 种商品，每个 ID 对应一个 `<id>.glb` 模型与 `<id>.png` 实际渲染预览。完整元数据见 `catalog.json`；完整清单和接入方式见 [使用说明](../../../../docs/PRODUCT_ASSET_LIBRARY.md)。

打开游戏首页的「商品素材库」，或访问 `?assets=1`，即可分类搜索、旋转查看、复制调用代码和下载模型。

## 来源

- `milk` / `bread`：保留原 `src/sim3d/assets.ts` 程序化模型。面包表面使用项目既有生成贴图，详见 [原素材来源](../../../../docs/ASSET_SOURCES.md)。
- 其余 28 种：本轮项目内编写的几何、PBR 材质与原创包装标签。无外购模型或运行时外部图片接口。
- GLB：Babylon.js 官方导出器从上述同款模型导出，贴图内嵌；不包含预览展台、相机或灯光。
- PNG：上述模型的实际浏览器渲染，不是概念图或替代商品的贴片。

包装为英语教学用虚构商品，无真实商标或认证标记。本记录不另行更改项目或既有素材的授权。

## 完成度

全部 30 种都有模型、双语名称、单位表达、陈列建议与独立 ID，并已接入游戏的自选进货、门口签收、上架和收款。回到小店按 B 选择商品及数量即可下单；没有选择的商品不会自动采购。

本地词音录音仍只有 `milk`、`bread`，其他商品在游戏内可使用浏览器合成朗读。GLB 的接入标记与当前目录同步，几何、材质和内嵌贴图保留。
