# 第一人称 3D S0：实现与验收

记录日期：2026-08-30。对应 [PRD v0.2.1](./PRD.md) 的 S0 可玩技术小样。

核心经营闭环已在本机真实键鼠试玩中走通。S0 用来验证商品是否认得出、搬运与收银是否好操作，不等于完整超市模拟器、研究版 P0 或正式美术验收通过。

内置单词录音已在浏览器完成播放检查，宽／窄窗口的商品近看和词义卡片已作实图检查。仍需用户确认扬声器听感、操作舒适度和美术观感；不将技术检查当作用户验收。

## 1. 本机运行与入口

需要 Node.js 22 或更高；本轮使用 Node 26。

```bash
npm install
npm run build
npm run play
```

- 固定试玩入口：[http://localhost:4200/](http://localhost:4200/)。生产构建预览，改代码后需要重新 build、刷新。
- 开发入口：运行 `npm run dev:3d`，打开 [http://localhost:4199/](http://localhost:4199/)。支持热更新。
- 两个专用命令只监听本机，端口占用时明确报错，不自动切换到其他端口。
- `4199`、`4200`，以及 `localhost`、`127.0.0.1` 是不同浏览器存档来源；需要迁移进度时使用 JSON 导出／导入。
- 之前的 `4174` 页面不能作为当前项目运行或验收的证据。
- [旧 2D 原型](http://localhost:4200/?legacy=1) 和旧存档独立保留，不自动迁移或删除。

## 2. 当前已实现

### 场景、商品与操作

- Babylon.js 9.23.0 + TypeScript + Vite；一间第一人称可走动的小店，包含冰柜、面包架、柜台与家具碰撞。
- 牛奶有折顶奶盒、旋盖和标签；面包有独立外形、割口、表面材质与透明包装，不是仅换颜色的同一种方块。
- WASD／方向键移动；鼠标观察；E 抱箱、上架、扫描和收款；F 近看；G 在安全卸货点放箱或放回单品；Esc 暂停。
- 不支持鼠标锁定时，可按住画面左键拖动视角，或用 I／J／K／L 转头。本轮内嵌浏览器已用此方式完成试玩。
- 显示方向、距离和明确动作；底部按钮与键盘遵循同一实际目标及距离限制，不隔空拿货。
- 开场目标跟随当前手持货物：近看当前商品 → 逐件上架 → 空箱按 G 放下 → 下一种商品。近看是建议，不是开店的强制英语门槛。

### 有限库存经营闭环

- 初始现金 £0，牛奶、面包各 4 件为免费测试货；这不是正式经济平衡或采购系统。
- 每件商品有唯一编号和唯一归属：货箱、手持、货架、顾客篮子、收银台或已售出。
- 一次一位顾客，依次取牛奶和面包，前往收银台，付款后离店。下一位顾客不会凭空补货。
- 牛奶 £1.60、面包 £2.40，一单 £4.00。逐件扫描去重，全部扫描且付款成功后才入账；重复操作不重复收款。
- 普通容量升级花费 £8，使每种商品的可用货位从 4 增至 8；不检查英语等级，不增加现有商品，也不扩建店面。
- 仅有初始 8 件货，最多完成 4 个两件商品订单；售完后可导出存档或两步确认重新试玩。

### 商品与英语对应

- 近看显示 `milk / 牛奶 / a carton of milk`、`bread / 面包 / a loaf of bread`，可拖动观察商品。
- `milk`、`bread` 已接入本地英式真人 Ogg 录音，用户点击触发，遵守音量设置；播放失败明确提示，不伪报播放完成。
- 搭配与 `Card, please.` 仍依赖浏览器可用的英语语音。无语音时明确说明缺失，不以单词录音冒充整句。
- 暂停、失焦、隐藏页面及退出近看会停止发音；近看或听过只记录“接触”，不计独立掌握。

### 存档与恢复

- 使用独立 v3 完整快照，统一保存库存、手持货物、顾客阶段、扫描记录、交易、现金、升级和玩家位置。
- 主存档键为 `english-high-street:sim3d:v3`；保存前保留上一份有效快照，读取坏档时尝试回退并提示。
- 支持 JSON 下载、原生文件选择、完整校验、摘要预览和二次确认导入；确认后替换快照并重建场景，覆盖前保留当前有效快照。
- 支持取消未付款订单并归还商品、两步确认重新试玩；存储空间或权限错误明确显示，不冒称已保存。
- 支持多标签写入保护：优先持有页面生命周期 Web Lock；第二页只读。无 Web Locks 时比较原始快照全文，发现冲突即停止写入，不凭较大 revision 覆盖另一页。
- 已处理重复初始化、旧场景晚到回调、热重挂锁释放和页面返回时重新读取存档；设置同样遵守只读限制。

## 3. 已完成的真实试玩验收

环境为本机内嵌浏览器，使用真实键鼠交互与原生文件选择流程；不是只检查代码或通过隐藏状态直接跳到结果。

| 场景 | 实际结果 |
| --- | --- |
| 搬运与上架 | 初始牛奶、面包各 4 件；抱箱、近看、逐件上架通过。上架 4 件后再次操作被拒绝，没有凭空增加第五件。 |
| 安全放箱 | 可在指定安全点放下货箱，继续搬运另一箱。 |
| 顾客购物 | 开门后顾客自主依次拿两种商品，携篮到收银台；人物与篮子的位置已在实图中确认。 |
| 扫描中刷新 | 扫描牛奶后刷新、继续营业，扫描状态及货物正确恢复，未提前入账。 |
| 收款与去重 | 扫描第二件后付款收入 £4；继续按 E 不重复增加收入。 |
| 普通容量升级 | 第二单后资金 £8；Esc 菜单购买升级，扣除 £8，每种货位 4 → 8，现货数量不变，无英语门槛。 |
| JSON 恢复 | 原生选择文件后显示校验预览；取消保留当前进度；确认后替换快照、重建场景并成功继续。 |
| 单词播放 | 点击 milk / bread 后媒体元素实际进入播放，分别播放到 1.20 / 1.15 秒并触发结束，界面随后显示完成；退出近看可停止并复位播放。 |
| 近看布局 | 1365 × 860 与内嵌原生 538 × 703 窗口下，商品、词义、按钮与署名没有互相遮挡；牛奶可拖动旋转至侧面阅读包装。 |

实际运行截图：[面包近看（桌面）](./screenshots/s0-bread-inspection.png)、[牛奶近看（窄窗口）](./screenshots/s0-milk-narrow.png)、[面包近看（窄窗口）](./screenshots/s0-bread-narrow.png)。这些是本轮运行截图，不是概念图。

补充浏览器检查已确认：首个页面可进入游戏，第二页明确只读；关闭首个页面后，第二页可以读取最新进度并接管。此项不代表完成了整个外部浏览器兼容性矩阵。

## 4. 自动检查与修复记录

截至本记录，全仓库单元测试为 **8 个文件、121 项用例通过**，包含既有 2D 测试与新增 3D 测试；TypeScript 检查、生产构建和差异空白检查通过。

3D 覆盖范围包括：库存守恒、错误货架与容量限制、扫描／支付去重、付款失败与取消、普通升级无英语门槛、坏档回退、多页写入冲突、导入确认／取消、启动与页面生命周期、音频完成／失败／打断、资产结构与模型坐标。

顾客曾出现人物与提篮错位：模型在已移动的父节点下测量尺寸，把世界坐标偏移再次算进摆放。现由 `modelPlacement.ts` 在模型自身坐标系测量、缩放并落地，再挂回顾客父节点；新增 4 项 NullEngine 回归，覆盖不同路线位置／旋转与无效几何体，实图位置也已复核。NullEngine 测试不替代最终渲染观感检查。

`npm run test:e2e` 仍是旧 2D Chromium 回归，显式使用 `?legacy=1` 和独立 4201 端口；**本轮未运行这组旧 e2e，也不将它当作 3D 端到端验收通过。** 当前 3D 端到端证据为上节列明的实际试玩。

## 5. 待确认与未实现

### 需要用户确认

- 内置单词已通过浏览器播放状态检查，但实际扬声器音量与听感需要用户试玩确认。
- 商品是否一眼认得、近看细节是否足够，以及移动和搬运是否舒适。宽／窄窗口布局检查不能替代这些主观验收。

### 明确未完成

- 再采购、完整营业日、多位顾客并行、自由装修、扩店和高级自动化。
- 英语任务评测、独立掌握判定、学习效果验证与研究数据采集。
- 专门的伸手取货、握篮和刷卡动画精修。现有成人模型提供 idle／walk，拿货主要是库存归属状态转换；手部仍为程序化小样精度。
- 登录、麦克风、运行时 LLM、云存档、PWA 和移动端输入适配。
- Windows、Safari、Firefox 的真实设备验收，以及完整跨浏览器／持续性能测试。1365 × 860 窗口曾观察到约 120 FPS 的瞬时读数，不能当作持续基准、最低配置或性能承诺。
- 正式美术质量验收。认可的概念分镜不能替代对运行中模型、材质和近看效果的确认。
