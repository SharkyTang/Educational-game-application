# 顾客从街道进店

## 当前行为

- 每位新顾客从店门左侧或右侧约 19 米外的人行道走来，再通过店门前往购物清单上的货架。按已保存的顾客种子与序号交替选边，同一位顾客刷新不会重新抽取身份或来店方向。
- 来店过程显示“顾客正从街上走来”和方向、距离。真正跨过门口后才响一次门铃，并按原设置播放问候；关闭自动语音时仍保留字幕和手动重听。
- 保持此前的 1.41 米/秒走速与货架停顿。来店步行计入营业时间；不额外延长营业日、修改来客间隔或增加同时在场的人数。
- 路线避开街边树池、路灯、长椅、花箱和已放下的货箱，并保持在人行道上、不进入货车行驶区域。入店后沿当前装修布局取货，兼容 30 种商品和一次实体扩建。
- 搬动货箱时从顾客当前位置重算路线，不把正在走路的顾客送回出生点。首选远端无法通行时，新顾客可改从另一侧出发；两边都被堵住则等待清出通路。

## 暂停、存档与边界

暂停、失焦、学习语音期间继续沿用现有的动作暂停规则；恢复后从暂停位置继续。到达门口只是画面事件，只有真正到达货架才取走商品，不提前改变库存、交易或现金。

本次不增加存档字段。存档保留顾客身份、购物清单、支付状态和购物阶段，不保存逐帧坐标：若在前往第一件商品的阶段刷新，会从该顾客对应的街道远端重新演出走入过程；已进入后续取货或结账阶段的顾客不会重新从远处走来。载入本身不响门铃，恢复后实际跨门时才响。

离店仍沿原路线走出门口后结束，本次没有新增街道行人、多人排队或远距离离场动画。玩家 Shift 加速、货车、经营规则与存档版本保持不变。

## 实现与回归

- `src/sim3d/customerJourney.ts`：两侧出生点、街道与室内分段寻路、门口连接点。
- `src/sim3d/world.ts`：当前位置重规划、逐帧移动与真正跨门的通知；修正提前跳过近距离路点导致的拐角切入障碍。
- `src/sim3d/App3D.ts`：来客提示、跨门铃声与问候；`domain.ts` 仅同步来客提示文字，不改业务规则。
- `tests/unit/sim3d-customer-journey.test.ts`：真实街景、两侧与 30 商品、满载收货、扩建装修、备用路线、重规划、暂停/取消及跨门事件。
- `tests/unit/sim3d-startup.test.ts`：跨门前不问候、不响铃；跨门后不推进库存或写入购物阶段，兼容恢复与语音设置。
- `tests/e2e/sim3d-customer-arrival.spec.ts`：通过正常导入/导出和操作，在真实时间中验证左右来客、距离缩短、暂停与刷新、实际进店问候及最终到达收银台，并保留阶段截图。

完整检查：`npm run check` 与 `npm run test:e2e`。
