# 玩家走动与 Shift 加速

- 普通走速：2.8 米/秒（原先 1.85 米/秒，提高约 51%）。
- 搬箱走速：2.2 米/秒（原先 1.45 米/秒，提高约 52%）。
- 按住左 Shift 或右 Shift，再用 WASD / 方向键移动，速度为普通状态的 1.8 倍：空手约 5.04 米/秒，搬箱约 3.96 米/秒。
- 长按就持续加速，不需要反复点击；松开 Shift 恢复走速，不消耗体力，也不会自动切换为持续奔跑模式。
- 只按 Shift 不会自行移动；斜向移动不会比直行更快。Shift 不改变鼠标灵敏度、键盘转头速度或镜头视野。
- 暂停、切出页面、窗口失焦或释放鼠标控制时会清除按键状态，避免回来后卡在加速或自行走动。如果仍物理按住 Shift，回来后重新按方向键仍可加速；不会自动恢复移动。

玩家位移按真实帧间隔计算，低帧率时拆成最多 0.05 秒的小步做碰撞检查；单帧最多补算 0.25 秒，避免卡顿后突然跳过很长距离。货车和顾客原有速度保持不变。

主要参数与 Shift 判定集中在 `src/sim3d/playerMovement.ts`，实际输入、碰撞与逐帧移动在 `src/sim3d/world.ts`。此功能不增加存档字段，也不改库存、金额或订单规则。

## 回归覆盖

- `tests/unit/sim3d-player-movement.test.ts` 使用真实移动、输入和碰撞方法，覆盖步行/搬箱、左右 Shift 与双键交替、松键、斜向归一化、低帧率、薄墙，以及暂停/失焦/鼠标释放后的恢复。
- `tests/e2e/sim3d-player-movement.spec.ts` 通过正常存档导入/导出测量实际位移；用合法待签订单让货车先停靠，再对比步行、左右 Shift 长跑和松开后的速度。也检查仅按 Shift 不移动、暂停不移动、Shift 一直按住跨暂停后重新按方向仍能加速。
- 该测速用例关闭追踪录像与逐操作 DOM 快照，避免采样等待时间混入按键时长；仍保留动作追踪、失败截图、位移记录，以及页面和资源错误检查。其余浏览器用例的追踪配置不变。
- 全量检查：`npm run check`；浏览器回归：`npm run test:e2e`。浏览器计时允许帧调度误差，精确速度和碰撞边界由单元测试验证。
