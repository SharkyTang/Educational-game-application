# 店铺成长第二版：设备经营与第二次扩建

第二版把第一版的自由装修继续推进为真实经营系统。玩家可以在管理面板购买设备，购买后的设备先进入仓库；只有在「自由装修」中摆进店内并保存布局后，设备才会生成模型、碰撞、取货点和对应商品货位。收回仓库不会出售设备，也不会返还现金，原有设备、商品、订单与资金保持不变。

## 本版可购买设备

| 设备 | 价格 | 真实陈列位 | 可选商品范围 |
| --- | ---: | ---: | --- |
| 窄款壁式货架 | £6 | 12 | 常温食品、日用品中可放入 authored slot 的商品 |
| 低款双面货架 | £10 | 32 | 常温食品、日用品中可放入 authored slot 的商品 |
| 双层紧凑横式冷柜 | £12 | 24 | 可放入冷柜 slot 的冷藏商品 |
| 加宽横式冷柜 | £18 | 48 | 可放入冷柜 slot 的冷藏商品 |
| 阶梯果蔬架 | £10 | 12 | 可放入果蔬 slot 的商品 |
| 玻璃面包陈列柜 | £12 | 12 | 可放入柜体 slot 的烘焙商品 |

购买时必须指定该台设备陈列的商品。同一设备的商品位互相独立，商品仍需进货、签收并亲手上架；设备购买不会生成库存。普通设备只检查资金与商品适配，不以英语等级作为门槛。

## 仓库与装修

- 每次购买产生稳定的设备实例和独立购买记录，重复购买编号不会再次扣款。
- 仓库保存所有尚未摆入店内的已购设备；店内和仓库数量都从存档资产及布局实时计算。
- 装修草稿可以摆入、收回、拖动和旋转已购设备。只有通过边界、重叠、入口、卸货区以及顾客服务点可达性校验后才能应用。
- 摆入店内的设备才提供额外货位。收回前必须没有商品留在该台设备上，防止库存失去物理位置。
- 顾客会前往实际存有目标商品的原货架或新设备；补货、取货、取消订单和重载都保留明确的设备与货位归属。

## 第二次实体扩建

小卖铺第一次扩建仍为 £15、向后增加 3 米。第二版开放第二次扩建：再支付 £30，后墙再向后增加 3 米，总面积从约 83.0 m² 增至约 103.4 m²。两次改造各自记录购买日，并在对应营业日作为建设支出显示；不赠送库存，不改变原有 £8 普通货架扩容。

小卖铺仍有第 3 次实体扩建与升级社区超市两个后续阶段。自助收银、员工招聘、自动补货和超市经营不在第二版范围内；素材库里的两款自助收银台仍只是模型预览，不会绕过当前人工扫码、现金找零或刷卡规则。

## 存档与核验边界

设备资产、设备购买流水、店内摆位、两次扩建日期、每日设备投资支出与货位归属都会进入新版本存档。旧存档只读迁移：资金、现金抽屉、库存、订单、顾客、营业钟、社区记录、既有装修与日结保持原样，设备资产从空开始，不会补扣或补发现金。

验证需要覆盖纯规则单测、NullEngine 设备实例与变换测试、旧存档迁移、存档损坏回退、设备购买与仓库浏览器流程、摆放后上架及顾客取货，以及完整 `npm run check` 和全套 Chromium E2E。
